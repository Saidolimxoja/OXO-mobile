# OXO — мобильное приложение (Android)

Отчёты техников о работах и трек в рабочее время для «Ишлар ҳисоботи», отметка прихода
для «Давомат».
Сервер — бэкенд OXO, API `/api/mobile/*`; вход той же учётной записью OXO
(у пользователя должна быть включена «Мобил илова» и привязан сотрудник).

## Что умеет

- Вход, автообновление токена, выход.
- Бош саҳифа: сотрудник и рабочий день (праздники с сервера), норма за день/неделю/месяц,
  состояние трека, «Иш қўшиш», сегодняшние работы.
- Новая работа: на выезде (с местом по GPS и адресом) или удалённо (телефон/AnyDesk),
  вид работы, организация, что сделано, номер обращения, заявитель, время, 1–4 фото.
- Ишларим: работы за любой день за 90 дней, детали и фото; сегодняшние можно удалить.
- Трек: Пн–Пт 09:00–18:00, не в праздник — точки GPS и сигнал «на связи» раз в минуту,
  отправка раз в 2 минуты, без интернета копится на телефоне. Работает как foreground-сервис
  с постоянным уведомлением.
- Давомат: «Келдим» — свежая точка GPS в радиусе офиса и снимок лица в овале (камера
  снимает сама, когда лицо в кадре); сервер сверяет лицо с фото из анкеты. Ухода нет:
  выходы из офиса, тумана и вилоята сервер видит по треку. Вкладка «Давомат» —
  переключатель месяца, сводка за месяц и история дней.
- Языки: ўзбекча (кирилл, лотин), русский; светлая и тёмная тема.

## Структура `lib/`

- `api/` — HTTP-клиент, модели и методы `/api/mobile/*`.
- `screens/` — вход, оболочка с вкладками (`main_shell`), Бош саҳифа, Ишларим, форма работы,
  Давомат, профиль.
- `services/` — сессия и токены, геопозиция, трек (foreground-сервис), отметка прихода.
- `widgets/`, `theme.dart`, `i18n.dart` (строки на трёх языках).

## Сборка

Нужны Flutter SDK и Android SDK (Android Studio). Проверка: `flutter doctor`.

```
powershell -ExecutionPolicy Bypass -File build-apk.ps1 -ApiUrl https://<адрес API>
```

Готовый файл — `OXO.apk` в корне проекта.

Иконка — знак UNICON SOFT, исходники в `assets/icon`. После их замены:
`dart run flutter_launcher_icons`.

Запуск на телефоне по USB (режим разработчика + отладка по USB):

```
flutter run --dart-define=API_BASE_URL=https://<адрес API>
```
